# Markdown 富文本编辑器 MVP 设计文档

> 日期：2026-08-14
> 技术栈：Tauri 2 + Rust + React 19 + TypeScript + Vite + TipTap 3

## 1. 目标

用 Rust/Tauri 快速搭建一个**属于自己的富文本编辑器**，第一版（MVP）以本地 Markdown 文件为编辑对象，提供所见即所得编辑 + 本地文件读写闭环。

## 2. 技术选型

| 层 | 选型 | 说明 |
|---|---|---|
| 应用外壳 | Tauri 2.x | Rust 后端 + 系统 Webview |
| 编辑内核 | TipTap v3 / ProseMirror | 成熟稳定，官方 Markdown 序列化支持 |
| 前端 | React 19 + TypeScript + Vite | 包管理 pnpm |
| 文件格式 | Markdown | 通过 `@tiptap/markdown` 解析/序列化 |
| 图片 | 复制到文档旁 `assets/` | 文档文件夹自包含，markdown 存相对路径 |
| 状态管理 | React 原生 state + ref | MVP 够用，无需引入额外库 |

## 3. 架构

```
Tauri 2 App
├── src-tauri (Rust 后端)
│   ├── src/lib.rs
│   │   ├── open_document   # 弹窗选 .md → 读取内容
│   │   ├── save_document   # 写入；path 为空时弹「另存为」
│   │   └── import_image    # 选图 → 复制到文档旁 assets/ → 返回相对路径
│   └── 插件：tauri-plugin-dialog
└── src (Web 前端)
    ├── App.tsx             # 编辑器实例 + 文件操作 + 状态
    ├── components/
    │   ├── Toolbar.tsx     # 格式化按钮 + 打开/保存
    │   ├── StatusBar.tsx   # 文件路径 / 脏状态 / 字数
    │   └── LinkModal.tsx   # 链接 URL 输入弹窗
    └── extensions/
        └── image.ts        # 自定义 Image：相对路径 → asset 协议 URL
```

### 数据流

- **打开**：`open_document`（Rust 弹窗 + 读文件）→ `editor.commands.setContent(md, { contentType: "markdown" })`
- **保存**：`editor.getMarkdown()` → `save_document(path, content)`（path 为空走另存为）
- **图片**：`import_image` 复制文件 → `editor.chain().setImage({ src: "assets/xx.png" })`，渲染时用 `convertFileSrc` 转成可加载的 asset URL，保存时仍是相对路径

### 关键技术点

1. **TipTap v3 Markdown**：StarterKit 已内置 Link/Underline/Code/UndoRedo；需额外引入 `@tiptap/markdown`（`Markdown` 扩展）、`@tiptap/extension-image`、`@tiptap/extension-placeholder`。
2. **图片相对路径**：markdown 保存 `assets/xx.png`；自定义 `RichImage` 扩展覆盖 `renderHTML`，在展示时基于文档所在目录拼接绝对路径并经 `convertFileSrc` 转换。`tauri.conf.json` 需开启 `assetProtocol` 并放行 `**`。
3. **脏状态**：`onUpdate` 中通过 `suppressDirty` ref 屏蔽程序化 `setContent` 触发的更新。
4. **文件 IO 全部走 Rust 命令**，规避前端 fs 插件的 scope 限制，安全边界集中在 Rust 侧。

## 4. MVP 功能范围

- 基础行内：粗体、斜体、下划线、删除线、行内代码
- 段落结构：H1-H3、无序/有序列表、引用块、代码块、分割线
- 超链接：插入 / 编辑 / 移除
- 图片：本地选图 → 复制进 `assets/` 并插入
- 闭环必备：撤销/重做、打开 / 保存 / 另存为、脏状态提示

## 5. 环境要求

- Rust ≥ 1.94，Node ≥ 22，pnpm ≥ 10
- Ubuntu 需安装 Tauri 2 系统依赖（见下文）

## 6. 需要运行的命令

### 6.1 系统依赖（需要 sudo，一次性）
```bash
sudo apt update
sudo apt install -y libwebkit2gtk-4.1-dev build-essential curl wget file \
  libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev libsoup-3.0-dev
```

### 6.2 安装前端依赖（一次性）
```bash
pnpm install
```

### 6.3 启动开发环境
```bash
pnpm tauri dev
```
首次会触发 Rust 全量编译（3-10 分钟），之后增量很快。若只想跑前端热更新：
```bash
pnpm dev   # 仅 vite，编辑器功能需 Tauri 后端命令，仅供调试 UI
```

### 6.4 构建与检查
```bash
pnpm build            # 前端 tsc + vite 构建
cd src-tauri && cargo build   # 仅 Rust 编译（慢，可后台跑）
pnpm tauri build      # 打包发布产物
```

## 7. 已知取舍 / 风险

- **Markdown 往返丢失**：图片尺寸/对齐等富文本属性无法存入 Markdown，MVP 可接受；底层仍是 ProseMirror JSON，后续可平滑切换到 JSON 存储或支持更多格式。
- **未做关闭前确认**：窗口关闭时不拦截未保存内容，仅状态栏提示（后续可加 `onCloseRequested`）。
- **Ubuntu 必须用 webkit2gtk-4.1**（Tauri 2 专用），勿误装 4.0。
- **无自动化测试**：桌面 GUI，以手动验证为主。
