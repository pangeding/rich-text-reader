# 进阶方向

> 日期：2026-10-20
> 项目：Tauri 2 + React 19 + TypeScript + TipTap 3 Markdown 编辑器
> 范围：仅记录后续可探索的能力与方向，不包含当前缺陷修复与具体实施计划
> 关联文档：`2026-10-20-现状审查与优化方案.md`、`2026-10-20-第一步-未保存保护.md`

## 1. 编辑体验

- **暗色主题**：CSS 变量已铺好，成本最低，优先做。
- 可调字号 / 页宽 / 行距，提供舒适阅读与写作模式。
- 源码 ↔ 预览切换，兼顾 Markdown 精确控制与所见即所得。
- 文档大纲侧栏，长文导航。
- 专注模式、打字机模式。
- 命令面板（快速执行格式化、打开、导出等操作）。

## 2. 富文本能力

- 表格、任务列表。
- 代码块语法高亮（lowlight）。
- KaTeX 数学公式、脚注。
- 图片缩放、对齐、图注。

注意：图片尺寸、对齐、图注等属性无法无损写入纯 Markdown，需要约定 HTML 内嵌或自定义语法，会牺牲部分兼容性。是否接受这一取舍，是启用这些能力前必须先决定的问题。

## 3. 文件与工作区

- 多标签编辑。
- 侧边栏文件树 / 工作区概念。
- 最近文件列表。
- 自动保存 + `.bak` 备份 + 版本历史。
- 全文搜索（当前文档 / 整个工作区）。

## 4. 导出与发布

- 导出 HTML / PDF / Word。
- 打印样式。
- 一键复制为 HTML / Markdown。
- 导出时把图片打包或内联，保证产物自包含。

## 5. 工程化与发布

- GitHub Actions 多平台构建。
- Tauri WebDriver e2e 测试。
- `tauri-plugin-log` 日志上报与排查。
- 自动更新（updater）。
- 代码签名与安装包分发。
- 国际化（i18n）。

## 6. 存储演进

- 把 Markdown 降级为导入 / 导出格式，主存改用 ProseMirror JSON。
- 从根本上解决图片尺寸、对齐等富文本属性的往返丢失问题。
- 迁移时提供 Markdown → JSON 的一次性转换，并保留 Markdown 导出能力。

## 7. 选择建议

按投入产出排序，建议优先考虑：

1. 暗色主题（成本最低、感知强）。
2. 表格 / 任务列表 / 代码高亮（高频写作需求）。
3. 大纲 + 多标签（长文与多文件场景）。
4. 自动保存 + 版本历史（与稳定性建设互补）。
5. 导出 HTML / PDF（分享与归档需求）。

同一阶段建议只选 1–2 条，避免同时铺开导致质量下降。
